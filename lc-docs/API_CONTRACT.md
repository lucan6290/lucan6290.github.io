## ID 规则

```text
人物：c001、c002、c003……
场景：s001、s002、s003……
道具：p001、p002、p003……
```

- 三位数，按**全剧首次出场顺序**编号
- 三类编号互不影响，可同时存在 `c001`、`s001`、`p001`
- 类内唯一、序号连续无空洞
- ID 不承担语义。不得把拼音、场景名、光影、服装名塞进 ID，语义全部放在中文名称里
- 禁止输出 `CHAR_xxx`、`SCN_xxx`、`record_id`、`recXXXXXX` 这类旧格式或平台内部 ID

`v###` 是**音色资产**的预留前缀。它由 `episode-prompt` 侧从 `c###` 机械派生（`v001` 对应 `c001`），**本 Skill 不产出、不写入资产表**。

## 人物

### 三级标题

```text
### c001 · 角色名 · 形象名     多形象角色
### c004 · 角色名              单形象角色
```

**角色名**是基础角色名，禁止带序号（`楚铮1`、`第1套楚铮` 都是错的）。同一角色的多条记录角色名相同、形象名不同，**必须连续排列**。这就是归组方式，没有额外的归属字段。

**形象名** 2–8 字，优先 4–6 字。禁止「常服」「古装」「现代装」这类过泛词，禁止 `第1套:` 这类前缀。单形象角色可以省略；该角色后来出现第二个形象时，回头给第一条补上形象名，ID 不变。

唯一性由 ID 保证，不靠名称。

### 字段

| 字段 | 必需 | 注入片段提示词 | 说明 |
|---|---|---|---|
| 出场集数 | 是 | 否 | **该套形象**的真实使用区间 |
| 外貌 | 是 | 否 | 视觉信息 + 静态气质结论，≤80 字 |
| 妆造 | 非人主体可省 | 否 | 视觉信息，≤60 字 |
| 小传 | S/A 级必填，B/C 留空 | 否 | 纯叙事，≤100 字 |
| 参考图 | 是 | 否 | 平台侧参考图类型 |
| 提示词参考 | 是 | 否 | 资产参考图的生图 Prompt |

**没有任何资产字段会被注入片段提示词。** 导演 Skill 的渲染模板只取 ID 与名称——人物长什么样由参考图承载，提示词里再写一遍既浪费长度，又会与参考图打架。

这些字段的真实去向是两处：

1. **生成参考图**。`提示词参考` 直接提交生图模型；`外貌`、`妆造`、`描述` 是它的事实来源
2. **供人和 AI 理解**。人工审校读它们，导演 Skill 读它们来写准站位与动作

`小传` 只有第 2 个去向。

### 参考图

基础受控词表：

```text
face
full_body
half_body
```

特殊主体可自定义补充（大白鲨的 `fin_surface`、`breach`）。自定义词在全表内必须保持一致，不得同义多写。

## 场景

### 三级标题

```text
### s001 · 场景名                 常规
### s001 · 场景名 · 状态名         同一物理空间因布置变化拆出多条时
```

状态名的用法与人物形象名一致：同一物理空间发生婚礼、葬礼、战损、改造这类重大布置变化时拆成多条记录，用状态名区分并连续排列。只是时段不同**不拆**，用「时段」变体承载。

### 字段

| 字段 | 必需 | 说明 |
|---|---|---|
| 描述 | 是 | 空间构成 + 方位关系，**不得出现人物名**，≤100 字 |
| 时段 | 是 | 受控词表，逗号分隔 |
| 光影 | 是 | 与时段逐项对应 |
| 出场集数 | 是 | 该场景在全剧的出现区间 |
| 提示词参考 | 是 | 16:9 空间建立图的生图 Prompt |

### 时段

受控词表，只有四个值：

```text
清晨 / 日 / 黄昏 / 夜
```

列出该场景在全剧中**实际出现过**的时段，逗号分隔。导演 Skill 引用时写成 `s002@日`，时段必须在此列表内，否则组装脚本报错。

天气（雨、雾、雪）**不是时段**，归镜头描述。同一场景在不同时段的光照与氛围差异显著，必须显式区分。

### 光影

与时段逐项对应，格式 `时段：光源描述`，多项用 `；` 分隔：

```text
- 时段：日, 夜
- 光影：日：正午强光自顶部穿过椰叶，林下整体处于半阴；夜：月光为唯一主光源，礁石背面完全没入阴影。
```

时段里有几个值，光影就必须有几项，一一对应。

它的作用是让场景生图 Prompt 的光源自洽，并供人工审校。当前不注入片段提示词。

## 出场集数

格式：

```text
第1-3、5-8、13-17集
第4集
```

**非连续使用必须保留非连续性。** 禁止写「全剧」「全篇」「始终」，禁止把角色从第一次到最后一次出场的整段范围直接当成某套形象的使用范围。

只有当剧本证据确认该形象确实连续覆盖整个区间时，才允许写连续大范围。

自查：同一角色若有两套以上形象，而它们的出场集数大范围完全重叠，说明把角色总出场范围误写成了形象使用范围，必须回查。

## 统计与警告

文档末尾固定写六项：

```text
- 基础角色数：
- 人物形象资产数：
- 场景资产数：
- 道具资产数：
- `画风`：（取值）（来源：第几级）
- 警告：无 / 具体内容
```

「基础角色数」按角色名去重计数，「人物形象资产数」按记录条数计数，两者不同才说明拆过形象。

`画风` 取自第 4 级兜底、或项目设置与视听风格 front matter 不一致时，警告里各须有一条。

## 序列化

- 一条资产对应一个三级标题小节，不降级为表格行或编号列表
- `提示词参考` 内部的分段用 `<br>`，不用真实换行——它必须保持在一个 `- 键：值` 里
- 字段值中不写「待补全」「无」「TBD」这类占位符。真的没有就不写这一�

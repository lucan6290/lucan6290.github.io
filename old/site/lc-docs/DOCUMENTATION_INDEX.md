## 3. 站点模块 AGENTS.md 层级（逐级加载）

`site/` 下代码目录均有模块级 `AGENTS.md`（导航入口，Rule Router）。改站点时按 `项目根 AGENTS.md → Task Routing → 模块 AGENTS.md → site/lc-docs/FRONTEND_CONVENTION.md → 实现` 逐级加载。内容目录（`blog/`、`docs/`）不生成 AGENTS.md。

```text
site/AGENTS.md
├── src/AGENTS.md
│   ├── components/AGENTS.md
│   │   ├── BlogCategoryPage/AGENTS.md
│   │   └── BlogHomePage/AGENTS.md
│   ├── css/AGENTS.md
│   ├── pages/AGENTS.md
│   └── theme/AGENTS.md
└── plugins/AGENTS.md
    └── blog-category-pages/AGENTS.md
```

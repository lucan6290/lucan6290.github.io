## 1. 本地优先原则

本页记录归档站点规范。当前内容事实源为 `frontend/content/`，写作与构建约定见 [工程全局规范](../../../docs/GLOBAL_STANDARDS.md) 与 [内容指南](../../../docs/SITE_CONTENT_GUIDE.md)。

## 2. 运行端口（强制）

| 工程 | 端口 | 访问地址 |
| --- | --- | --- |
| 博客前端 | 3400 | `http://127.0.0.1:3400/` |

规则：

- 端口固定，不得因端口占用临时改端口。
- 启动前先检查端口占用，被本项目旧服务占用时先 `Stop-Process` 清理再启动。
- 博客前端本地开发须热更新启动（`npm run dev`）。

## 3. 内容事实源与派生数据

- 事实源：`site/docs`、`site/blog`（Markdown/MDX）。
- 配置源：`site/docusaurus.config.ts`、`site/sidebars.ts`、`site/blogSidebars.ts`。
- 构建产物：`site/build`、`site/.docusaurus`，不手工修改，不用于解决端口问题。

## 4. 文件命名 / slug / 路径片段规则

`slug`、`category_path[]`、图片名均按「单个路径片段」校验：

- 允许中文、英文、数字、连字符、下划线等普通字符。
- 非空，不能是 `.` 或 `..`。
- 不能含路径分隔符 `/`、`\`。
- 不能含 Windows 非法文件名字符 `< > : " | ? *`。
- 不能含控制字符，不能以空格或点号结尾。
- `category_path` 是字符串数组，每项都须满足片段规则。
- 文章文件名允许中文（slug 即文章文件名片段）。

## 5. 时间与日期

- 统一 ISO 8601 字符串并显式含时区，如 `2026-06-29T18:00:00+08:00`。
- blog `date` 至少以 `YYYY-MM-DD` 开头。
- 任务时间字段用 `started_at` / `finished_at`。

## 6. 语言与文案

- 内容与文档以中文为主；代码标识符使用英文。
- 代码注释遵循「当前文件同语言」原则。

## 7. 静态资源安全

- 图片上传限制扩展名（`.png/.jpg/.jpeg/.webp/.gif/.svg`）、大小（默认 ≤ 10MB）、安全文件名；校验扩展名、MIME、magic number；SVG 额外清理脚本与外链。
- 静态资源放在 `static/` 目录，通过根路径引用（如 `/img/favicon.png`）。
- 文章封面图放在 `static/img/covers/`，分类封面在 `categories.yml` 中引用路径。

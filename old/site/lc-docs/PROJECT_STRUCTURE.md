## 4. 站点工程（site/）

```text
site/
├── blog/                      # 博客文章（随笔感想、AI观察…）
│   ├── authors.yml            # 作者注册表
│   └── index.md               # 博客首页分类目录
├── docs/                      # 长期知识库（project-practice、tech-study…）
├── src/
│   ├── components/            # 自定义 React 组件（BlogCategoryPage、BlogHomePage）
│   ├── css/custom.css         # 全局样式
│   ├── pages/                 # 首页 / about / projects
│   └── theme/                 # 主题覆写（BlogSidebar、DocSidebar、Footer…）
├── plugins/blog-category-pages/  # 博客分类页插件
├── static/                    # 静态资源（img、favicon）
├── docusaurus.config.ts       # 站点与顶部导航配置
├── sidebars.ts                # docs 侧边栏
├── blogSidebars.ts            # blog 侧边栏
└── package.json               # 脚本与依赖
```

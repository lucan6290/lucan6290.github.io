## 1. 项目类型与定位

箓川码笺（xiaocancoding）公开站点是基于 Docusaurus 3 的内容渲染工程，承载博客、知识库与项目展示，面向读者。站点内容（Markdown/MDX）是项目的事实源，由管理后台（admin）读写校验。

| 工程 | 技术栈 | 角色 |
| --- | --- | --- |
| `site/` | Docusaurus 3 + React 19 + TypeScript | 公开站点（博客 + 知识库 + 项目展示），面向读者 |

## 2. 顶层目录

```text
xiaocancoding/
├── site/                      # Docusaurus 公开站点（本工程）
│   └── lc-docs/               # 站点端工程治理文档（本目录）
├── admin/                     # 管理后台（前后端），读写 site/ 内容
├── docs/                      # 项目整体规划文档
├── AGENTS.md                  # Agent 项目导航入口
└── README.md                  # 项目说明
```

## 4. 站点工程（site/）

```text
site/
├── blog/                      # 博客文章（随笔感想、AI观察…）
│   ├── authors.yml            # 作者注册表
│   └── index.md               # 博客首页分类目录
├── docs/                      # 长期知识库（project-practice、tech-study…）
├── src/
│   ├── components/            # 自定义 React 组件（BlogCategoryPage、BlogHomePage）
│   ├── css/custom.css         # 全局样式
│   ├── pages/                 # 首页 / about / projects
│   └── theme/                 # 主题覆写（BlogSidebar、DocSidebar、Footer…）
├── plugins/blog-category-pages/  # 博客分类页插件
├── static/                    # 静态资源（img、favicon）
├── docusaurus.config.ts       # 站点与顶部导航配置
├── sidebars.ts                # docs 侧边栏
├── blogSidebars.ts            # blog 侧边栏
└── package.json               # 脚本与依赖
```

## 5. 数据流概览

```text
站点内容（site/docs、site/blog，Markdown/MDX 事实源）
      │
      ▼  管理后台（admin）读写校验
      │
站点构建（site/ npm run build） → 部署到 GitHub Pages（.github/workflows/deploy.yml）
```

## 6. 事实源与派生数据

- **事实源（Source of Truth）**：`site/docs`、`site/blog` 下的 Markdown/MDX。
- **配置源**：`site/docusaurus.config.ts`、`site/sidebars.ts`、`site/blogSidebars.ts`。
- **构建产物**：`site/build`、`site/.docusaurus`，不应手工修改。
- 管理后台（admin）负责扫描、解析、校验、创建、编辑与构建站点内容，其治理文档见 `admin/lc-docs/`。

## 1. 本地优先原则

管理后端是「本地优先」工具，不引入独立数据库，以 `site/` 下的 Markdown/MDX 文件为事实源；后端只负责扫描、解析、校验、创建、编辑与构建。

## 2. 运行端口（强制）

| 工程 | 端口 | 访问地址 |
| --- | --- | --- |
| 博客前端 | 3400 | `http://127.0.0.1:3400/` |
| 管理前端 | 14000 | `http://127.0.0.1:14000/admin/` |
| 管理后端 | 18000 | `http://127.0.0.1:18000/` |

规则：

- 三个端口均固定，不得因端口占用临时改端口。
- 启动前先检查端口占用，被本项目旧服务占用时先 `Stop-Process` 清理再启动。
- 博客前端、管理前端、管理后端本地开发均须热更新启动（`npm run dev` / `--reload`）。

## 3. 内容事实源与派生数据

- 事实源：`site/docs`、`site/blog`（Markdown/MDX）、`admin/backend/data/content-schema/*.yml`。
- 派生数据：`registry_index.sqlite3`（可删除重建的查询索引）。
- 构建产物：`site/build`、`site/.docusaurus`，不手工修改，不用于解决端口问题。

## 4. 文件命名 / slug / 路径片段规则

`slug`、`target_slug`、`category_path[]`、`target_category_path[]`、图片名均按「单个路径片段」校验：

- 允许中文、英文、数字、连字符、下划线等普通字符。
- 非空，不能是 `.` 或 `..`。
- 不能含路径分隔符 `/`、`\`。
- 不能含 Windows 非法文件名字符 `< > : " | ? *`。
- 不能含控制字符，不能以空格或点号结尾。
- `category_path` 是字符串数组，每项都须满足片段规则。
- 文章文件名允许中文（slug 即文章文件名片段）。

## 5. 时间与日期

- 统一 ISO 8601 字符串并显式含时区，如 `2026-06-29T18:00:00+08:00`。
- blog `date` 至少以 `YYYY-MM-DD` 开头。
- 后端默认时区 `Asia/Shanghai`。
- 任务时间字段用 `started_at` / `finished_at`。

## 6. 安全边界

所有后端文件操作必须满足：

- 只允许访问项目根目录下的白名单目录（`site/docs`、`site/blog` 等）。
- 禁止 `..` 路径穿越；API 不接收任意绝对路径作为读写目标。
- 图片上传限制扩展名（`.png/.jpg/.jpeg/.webp/.gif/.svg`）、大小（默认 ≤ 10MB）、安全文件名；校验扩展名、MIME、magic number；SVG 额外清理脚本与外链。
- 网页抓取需 SSRF 防护（禁止 localhost/内网/file 协议）。

## 7. 鉴权约定

- 单管理员账号（环境变量 `LUCHUAN_ADMIN_USERNAME`/`LUCHUAN_ADMIN_PASSWORD`，本地默认 `admin`/`admin123`）。
- 后端签发 HMAC 签名 token，`Authorization: Bearer <token>`；`<img>` 等无法附加头的场景允许 `access_token` query 参数。
- 公开接口仅 `/api/v1/health` 与 `/api/v1/auth/login`，其余 `/api/v1` 均需鉴权。

## 8. 语言与文案

- 内容与文档以中文为主；代码标识符使用英文。
- 面向用户的错误提示（后端 `message`、前端 toast）使用中文。
- 代码注释遵循「当前文件同语言」原则，本仓库后端注释以中文为主。

## 9. 危险操作约定

删除、移动、同步、部署等有副作用的接口统一「预演优先」：

- `dry_run=true`（默认）只返回 `MutationPlanDTO` 影响计划，不实际改文件。
- `dry_run=false` 必须 `confirm=true`，否则返回 `400 confirmation_required`。
- 前端先 `dry_run=true` 展示计划，用户确认后再 `dry_run=false, confirm=true`。

## 10. 乐观锁约定

- 读接口返回文章 `version`（由 mtime/size 生成）与 `updated_at`。
- 保存文章必须传 `expected_version`，版本不一致返回 `409 version_conflict`。
- 不隐式覆盖；强制覆盖需单独 `force` 设计。

## 1. 项目类型与定位

箓川码笺（xiaocancoding）是一套「公开内容站 + 自建写作管理后台」的单仓（monorepo）全栈项目，共三个可独立运行的工程：

| 工程 | 技术栈 | 角色 |
| --- | --- | --- |
| `site/` | Docusaurus 3 + React 19 + TypeScript | 公开站点（博客 + 知识库 + 项目展示），面向读者 |
| `admin/frontend/` | Vue 3 + Vite + Naive UI + Pinia + ByteMD + TypeScript | 内容管理后台前端，面向作者 |
| `admin/backend/` | FastAPI + Uvicorn + Pydantic v2 + PyYAML + Python 3.10 | 内容管理后端，本地优先，读写站点文件 |

三者关系：管理后台（admin）读写并校验 `site/` 下的 Markdown / MDX 内容，`site/` 负责对外渲染。

## 7. 数据流概览

```text
作者（浏览器，管理前端 14000）
      │  /api/v1（axios，Bearer token）
      ▼
管理后端（FastAPI 18000）
      │  读写
      ├──▶ site/docs、site/blog（Markdown/MDX，内容事实源）

      └──▶ admin/backend/data/registry_index.sqlite3（可重建查询索引）
      │
      ▼
站点构建（site/ npm run build） → 部署到 GitHub Pages（.github/workflows/deploy.yml）
```

## 8. 事实源与派生数据

- **事实源（Source of Truth）**：`site/docs`、`site/blog` 下的 Markdown/MDX，以及 `admin/backend/data/content-schema/*.yml`。
- **派生/可重建**：`admin/backend/data/registry_index.sqlite3` 是查询索引，可删除重建；`site/build`、`site/.docusaurus` 是构建产物，不应手工修改。

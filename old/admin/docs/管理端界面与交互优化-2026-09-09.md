# 管理端界面与交互优化（2026-09-09）

## 需求与范围（Canonical Task State）

- 目标：现代、清晰、易操作的管理工作台；优先导航、仪表盘、文章管理及跨页一致性。
- 保留：Vue 3 / Naive UI / Pinia、现有路由、接口、文章状态语义及内容工作流。
- 不包含：后端、鉴权机制、API 契约、真实文章内容及依赖升级。
- 验收：桌面与小屏无整页横向溢出；深浅色一致；导航与筛选可键盘操作；加载/空/错误态清晰；尊重 reduced-motion。

- task_type: frontend；change_surface: [frontend_code]。
- required_rules（task-routing Base + Surface）：global, frontend。
- loaded_rules：global, frontend；missing_rules: []；completeness: 100。

- 条件规则：跨 views/assets/components，已加载各目录规则。不新增目录、不引入依赖。
- 证据：App.vue、admin-theme.css、Dashboard.vue、Posts.vue、router.ts、stores/posts.ts。

## Existing Implementation Discovery

- 复用 Naive UI 的主题、抽屉、弹窗、输入框和表格，不自建 UI 框架。
- 复用 postsStore 和 postDisplay 统计/分类/状态，复用 NewPostModal。
- 高频操作沿用页面现有方法；索引与站点维护入口折叠收纳，不更改工作流。
- 当前导航仅存在 App.vue；抽取展示组件以复用桌面与移动端菜单。

## 方案与交互契约

1. 视觉基础：克制的靛蓝、低对比背景、统一边框/间距/圆角/字体；移除全卡片升起和长时间逐行动画。
2. 应用外壳：桌面分组侧栏、顶部位置提示/快捷导航/主题切换，小屏焦点受控抽屉。
3. 快捷导航：Ctrl/Cmd+K，输入过滤页面，方向键选中、Enter 跳转、Esc 关闭；不产生业务写入。
4. 仪表盘：明确写作入口、统计筛选、快捷工作流、可操作文章列表；错误态提供重试。
5. 文章管理：标题与主要操作一行，筛选独立一行，维护操作收进菜单；分页/稳定 row-key、筛选重置、明确搜索空态。
6. 其他页面：统一主题、降低装饰开销，修正触控与小屏布局；登录仅调整展示，不改变认证。
7. 动效：短时 opacity/transform、无持续背景漂移、reduced-motion 全局禁用非必要动画。

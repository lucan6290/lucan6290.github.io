## 当前行为

- 进入新建写作状态即生成 `title/date/updated/description/tags/sticky` 六字段，顺序固定，字符串双引号、标签行内数组。标题/摘要留空供作者填写，无标签默认 `[]`，置顶默认 false。
- 开始写作时间使用真实北京时间，精确到秒并带 `+08:00`；初始 date=updated。等待后再保存不会把开始时间换成首次保存时间。

- README.md、AGENTS.md 不区分大小写豁免。其它工程说明/设计文档可选择说明用途；切换用途不静默丢弃脏缓冲。
- 已有完整六字段普通文章实际修改时维护 updated，date 不变。无变化或仅改 updated 不写盘；历史文档不自动补造日期。
- 用途只在当前编辑会话生效；重新打开默认自动识别，作者可选择本次按普通文章或说明文档编辑。不另建注册表，不向原文追加用途字段。
- 保存保留未知字段、注释、BOM 和换行，服务端时间响应不会覆盖请求期间新输入。另存按复制保留真实历史时间。

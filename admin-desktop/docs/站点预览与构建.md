# 桌面站点预览与生产构建

编辑器打开当前已保存文档在本地站点的地址，设置页可打开站点首页。预览与生产构建只使用已通过内容服务认证的工作区。工作区内应包含新站源码并已运行 `pnpm install`，系统 PATH 应提供 Node.js。

## 接口和实现

- `open_site_preview({ documentPath })` 返回预览 URL、进程所有权和日志路径。参数是内容根相对路径或 `null`。README 对应分类页，文档地址逐段编码，首页使用 `/`。预览展示磁盘上的内容。
- 固定绑定 `127.0.0.1:3400`。Vite 开发插件提供仅本地启动检查使用的 `GET /__luchuan_desktop_site`，返回 `{ service: "xiaocancoding-site", project_root, pid, route }`。原生端用规范化路径检查项目身份，用 PID 区分自有服务，且仅允许打开已校验的 3400 地址。
- 同工作区的外部 Vite 服务可复用。旧版、其他工作区和无关服务均报告占用冲突；外部进程由原启动者管理。
- `build_blog_site()` 执行内容生成、类型检查和 Vite 生产构建，返回退出码、产物目录（成功时）、日志路径与末尾输出。直接执行本地 Node CLI 并使用参数数组，自有进程使用原生 Job 管理。产物沿用 `frontend/dist/`。构建与预览启动串行，应用退出清理自有子进程。

## 实施与验证

- 核对固定端口、已保存内容和真实产物三项需求。接口沿用原生命令边界，HTTP 探针通过回环地址访问，进程所有权复用现有 Job，需求、方案、契约和架构检查通过。
- 先在临时目录与临时 HTTP 监听上写预览身份和路径回归，再实现 Vite 插件与原生预览、构建命令。测试监听只模拟响应。
- 挂载桌面操作按钮并检查加载、错误与构建日志状态。运行 Rust 格式、检查、测试，桌面和站点测试与构建，再审查改动和固定端口边界。

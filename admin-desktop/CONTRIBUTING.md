# 贡献指南

感谢对本项目的贡献！请遵循以下规范。

## 提交规范

- 格式：`类型: 简要描述`（中文描述），单次提交只含一个功能/一个修复
- 类型前缀：

| 类型 | 说明 |
|---|---|
| `feat:` | 新功能 |
| `fix:` | 修复 bug |
| `docs:` | 文档 |
| `refactor:` | 重构 |
| `perf:` | 性能优化 |
| `test:` | 测试 |
| `build:` / `ci:` | 构建 / CI |
| `chore:` | 依赖、杂项 |

> 版本发布提交用 `release: vX.Y.Z`，不纳入 CHANGELOG 分类。

## 开发流程

1. fork 并 clone 仓库
2. 创建功能分支
3. 提交前运行质量检查
4. 提交 PR，说明变更内容

## 报告问题

- **Bug 报告**：说明环境、复现步骤、预期与实际行为
- **功能请求**：说明使用场景与预期效果

## 代码规范

- 遵循项目已有的代码风格与 lint 规则
- 提交前通过全部测试

## 行为准则

参与本项目请遵守 [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md)。

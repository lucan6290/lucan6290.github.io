## 1. 已确认的方向

用户希望使用设计技能美化、完善博客，并明确：“现有这种主题风格就行”。

目标工程是 `frontend/` 自研 Vue 博客。延续白底、青绿色、首页手写标题、简洁列表与现有暗色主题。用更舒服的字号、清楚的信息层级和可发现的目录入口，完善首页到文章阅读的体验。

采用 design-taste-frontend 的现状检查与改版前后对照方法、frontend-design 的排版与一致性原则，以及 web-design-guidelines 的键盘、焦点和移动交互检查。用户的“保持现有主题”优先于技能的通用审美偏好，因此不机械套用随机视觉方向、图片数量、动效数量或禁止细分隔线等规则。

## 4. 具体改动

### 4.1 优先改善长文阅读

- 正文暂定桌面 17px、手机 16px，行高约 1.8～1.85；这是本次设计建议，并非用户指定的数值。
- 正文阅读区上限约 820px，并随目录可用空间缩小；保持相等内边距，手机两侧约 20px。
- 标题层级保持现有字体风格，调整段前段后间距；页面标题使用平衡换行，保留完整文字。
- 代码块字号约 14px、行高约 1.6；长代码与宽表格在各自容器内横向滚动，不撑宽整页。
- 调整段落、列表、引用、提示块和图片的间距，让正文有明确的段落节奏。
- 不更改文章源文件及其标题、内容和锚点生成规则。

### 4.2 手机目录采用紧凑的可展开入口

复用 `ResizableSidebar.vue` 和原有目录树。

- 996px 及以下，默认显示一行“栏目目录”按钮，展开后才显示目录树。
- 手机的展开状态与桌面侧栏偏好独立；进入新页面时收起手机目录，避免把桌面展开状态带到手机。
- 桌面继续保留宽度拖拽、键盘调宽及原有偏好记忆；跨断点切换时正确恢复。
- 按钮提供 `aria-expanded`、`aria-controls` 和清晰焦点，点击区域至少 44px 高。

手机文章首屏结构：

```text
站点名称                    栏目  主题
栏目目录（默认收起）

文章完整标题
作者与字数
日期与标签

正文从这里开始
                        本文目录入口
```

“栏目目录”用于跳转其他文章，“本文目录”用于定位当前文章章节，名称明确区分。

### 4.3 文章大纲有明确且可操作的入口

复用 `FloatToc.vue` 的标题收集、当前章节高亮和定位能力。

- 在文章页面右下方提供明确的“本文目录”按钮，桌面和手机均可点击，不依赖鼠标悬停。
- 按钮上方展开有边界的浮动面板，宽度不超过视口减 32px，高度不超过视口的约 70%，内容过长时内部滚动。
- 面板为非模态导航：不锁住页面、不强制焦点循环；打开时焦点进入目录，Escape 关闭并回到触发按钮，点击外部关闭。
- 手机点击章节后关闭面板；定位保留顶部导航的避让距离。减少动态效果模式下使用即时滚动。
- 没有可用章节时隐藏入口；路由切换后刷新章节与高亮，清理旧监听。继续以当前实际渲染出的 h2/h3 为范围，不在这次改版中重写 Markdown 层级。
- 面板浮动展示，不因开关改变正文宽度，避免阅读中的文字重新排版。

### 4.4 首页、列表与导航统一细节

- 保留现有首页文案、手写标题、两个阅读入口及“最近文章”区域。
- 最近文章标题允许两行显示，日期移为独立辅助信息，字号约 13px；不再让标签、标题、日期争抢一行宽度。
- 博客列表继续使用纵向列表，标题平衡换行，摘要约 16px，日期与标签保持清晰但次要的层级。
- 列表与文章标签统一为现有青绿色浅底样式、小圆角与一致字号；保留真实标签内容及链接。
- 顶部栏目根据当前路由显示选中状态；目录、主题和移动菜单控制补全可访问名称、开关状态和键盘退出行为。
- 保留当前主题图标和品牌 Logo；通过扩大按钮点击区域提升触控操作，不更换视觉语言。

## 5. 范围与复用

预计涉及以下现有文件，具体以实施时的最小必要差异为准：

| 文件 | 作用 |
| --- | --- |
| `frontend/src/components/article/MarkdownRenderer.vue` | 正文及代码、引用、表格等渲染样式 |
| `frontend/src/views/ArticleView.vue` | 阅读宽度、文章头部与标签 |
| `frontend/src/components/sidebar/ResizableSidebar.vue` | 手机目录展开行为 |
| `frontend/src/components/toc/FloatToc.vue` | 明确的大纲入口与可访问交互 |
| `frontend/src/views/HomePage.vue` | 最近文章排版与字号 |
| `frontend/src/components/list/ArticleList.vue` | 列表标题、摘要、标签的一致性 |
| `frontend/src/components/layout/Navbar.vue` | 当前栏目状态、移动菜单与触控区域 |
| `frontend/src/styles/tokens.css`、`base.css` | 仅在上述改动确需共享变量、焦点或减少动态效果规则时调整 |

继续使用 Vue、现有 CSS 变量、ByteMD、内容清单及现有目录组件，无新增 UI 依赖、API 或内容管线。知识库、标签、归档和项目页共用组件，会随排版改进受益，需进行回归；保留知识库首页仅展示 README 等既有约定。

本轮不扩展到搜索、评论、阅读统计、SEO/RSS、管理端、迁移或文章内容编辑。搜索虽出现在历史需求基线中，但属于独立功能，另行安排。

当前首页、关于页、基础样式、导航配置等已有未提交修改；实施从当前工作区继续，仅叠加本方案相关修改，不回滚、不混入既有迁移工作，不自动提交 Git。

## 6. 验收

1. 在 390、768、1440px 三种宽度检查首页、博客列表、长文、短文与知识库；浅色/暗色均无整页横向溢出，长标题不截断关键内容。
2. 手机正文实际字号至少 16px，进入文章时目录默认收起，标题与开头内容不再被展开的目录树挤出首屏。
3. 栏目目录和本文目录支持点击及键盘操作，两个目录含义明确；章节定位正确、不会被固定导航遮挡，切换文章后无旧章节残留。
4. 桌面目录调宽、收起/展开、偏好记忆和跨断点切换正常；导航、标签、排序、上一篇/下一篇和主题切换继续可用。
5. 长代码、宽表格、图片、提示块、公式/Mermaid 检查适配情况；共用组件在知识库页面不退化。
6. 运行 `pnpm test` 和 `pnpm build`；若发现基线问题，区分本次引入与已有问题。为涉及目录状态、路由刷新等可复现行为补充适当验证，不引入仅服务这次美化的大型测试框架。
7. 保存同页面、同宽度的改前/改后截图进行比较，人工查看整页和手机端。设计技能的通用审美计分不替代上述实际验收。

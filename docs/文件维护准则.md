
## docs 规则
1. `site/docusaurus.config.ts`  
   **只有 docs 一级分类变动时才同步修改**：
   - 新增一级分类：加入知识库导航
   - 删除一级分类：移除知识库导航
   - 重命名一级分类：更新知识库导航
   - 二级分类和文章变动：不改 `docusaurus.config.ts`

2. `site/docs/index.md`  
   **所有 docs 变动都要同步**：
   - 一级分类变动
   - 二级分类变动
   - docs 文章新增/删除/重命名/移动

3.  - `site/docs/index.md`  
    是 **docs 总目录页**。  
    记录整个 `site/docs` 下的全部内容：
    - 所有一级分类
    - 所有二级分类
    - 所有 docs 文章
    **只要这个一级分类下面的结构或文章变了，就要同步**。

    - `site/docs/<一级分类>/index.md`  
    是 **一级分类章节目录页**。  
    只记录这个一级分类下面的内容：
    - 该一级分类下的二级分类
    - 该一级分类下的文章


4. 二级分类目录页  
   例如 `site/docs/tech-study/ai-exploration/index.md`：  
   **每个二级分类目录都必须有 `index.md`**。  
   创建新二级分类时，要自动创建它的 `index.md`。

5. `site/sidebars.ts`  
   docs 分类和文章变动都要同步。

6. `admin/backend/data/content-schema/categories.yml`  
   docs 分类新增/删除/重命名/改显示名都要同步。

7. `admin/backend/data/registry_index.sqlite3`  
   docs 分类和文章变动完成后都要重建/刷新。



## blog 规则
下面是 blog 规则，按你给的 docs 规范格式整理：

1. `site/docusaurus.config.ts`  
   **只有 blog 一级分类变动时才同步修改**：
   - 新增一级分类：加入博客导航
   - 删除一级分类：移除博客导航
   - 重命名一级分类：更新博客导航
   - 改一级分类显示名：更新博客导航 label
   - blog 文章新增/删除/重命名/移动：一般不改 `docusaurus.config.ts`
   - 如果文章移动到新建的一级分类：需要把新一级分类加入博客导航

2. `site/blog/index.md`  
   **所有 blog 变动都要同步**：
   - 一级分类变动
   - blog 文章新增/删除/重命名/移动
   - blog 文章保存后如果影响目录展示字段，也要同步

3. `site/blog/index.md`  
   是 **blog 总目录页**。  
   记录整个 `site/blog` 下的全部内容：
   - 所有一级分类
   - 所有 blog 文章

   blog 没有二级分类，也没有一级分类自己的 `index.md`。  
   也就是说不存在：
   - `site/blog/<一级分类>/index.md`

4. blog 分类目录页  
   blog 分类只有一级目录。  
   **一级分类目录下不需要 `index.md`**。  
   创建新 blog 一级分类时，只创建分类目录，不创建分类目录页。

5. `site/blogSidebars.ts`  
   blog 分类和文章变动都要同步：
   - 一级分类新增/删除/重命名/改显示名
   - blog 文章新增/删除/重命名/移动
   - blog 文章保存后如果标题、slug、date 等影响侧边栏展示，也要同步

6. `admin/backend/data/content-schema/categories.yml`  
   blog 分类新增/删除/重命名/改显示名都要同步。  
   blog 文章新增到新分类时，也要确保该一级分类写入 `categories.yml`。

7. `admin/backend/data/content-schema/tags.yml`  
   blog 文章涉及标签时要同步：
   - 新建 blog 文章时，新增标签要写入 `tags.yml`
   - 后续如果支持编辑文章标签，也应同步 `tags.yml`

8. `admin/backend/data/registry_index.sqlite3`  
   blog 分类和文章变动完成后都要重建/刷新：
   - 分类新增/删除/重命名/改显示名
   - 文章新增/删除/重命名/移动
   - 文章保存后如果内容或 front matter 变化，也要刷新索引。

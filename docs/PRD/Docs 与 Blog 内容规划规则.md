# 知识库、博客与项目内容规划

> 更新：2026-10-29。本文负责内容定位；文件与渲染规则统一引用 [内容指南](../SITE_CONTENT_GUIDE.md)。

## 放置判断

| 内容特点 | 目录 | 示例 |
| --- | --- | --- |
| 长期可复用、围绕概念或方法组织 | `frontend/content/knowledge/` | 安装教程、算法笔记、技术参考 |
| 带有时间背景、个人过程或阶段结论 | `frontend/content/blog/` | 问题复盘、学习总结、观点随笔 |
| 介绍具体项目或工具及获取方式 | `frontend/content/projects/` | TerminalVoice、AgentKit、Orca |

一篇文章保持一个目录归属。需要关联时使用文章互链和标签，不复制出多份独立正文。

## 分类与标题

- 三栏都支持目录嵌套，目录自动生成分类，Markdown 自动生成独立文章。
- 分类名称按主题确定，可以使用中文和数字前缀；不要求英文路径或日期文件名。
- 标题描述明确主题；教程突出操作目标，复盘说明问题与结论，项目介绍说明实际用途。
- 需要顺序阅读的内容使用编号，通用话题用标签聚合。
- 项目页将自有项目与推荐项目分目录，Fork 明确标为二次开发并注明来源。

## 写作重点

知识库说明背景、适用环境、步骤、结果与参考；博客交代场景、尝试、取舍和结论；项目介绍说明功能、链接、许可及有依据的致谢和贡献方式。

稳定的方法可以从复盘中提炼为新的知识文章，两者互链，并明确各自目标。

## 维护与扩展

- 修改 Markdown 和配图即可更新内容，不额外维护路由、侧栏配置、分类数据库或目录快照。
- 图片使用 `文章名-images/`，小节用 `##`、`###` 进入本文目录。
- 需要稳定发布日期时填写 `date`，更新正文时按需维护 `updated`。
- 当前支持的字段见 [内容契约](../API_CONTRACT.md)；不使用未实现的元信息驱动功能。
- 系列专题属于待明确能力，不把 `series` 当作已支持功能。
- 文章路径变化后更新当前链接，不为历史地址添加兼容分支。

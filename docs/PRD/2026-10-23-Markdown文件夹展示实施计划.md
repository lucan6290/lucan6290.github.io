# Markdown 文件夹展示规则与验收

> 当前修订：2026-10-29。实现入口已存在；本文件作为当前验收说明，不重复授权执行任务。

## 当前行为

- `frontend/content/` 目录生成分类，Markdown 生成独立文章，支持嵌套。
- 知识库、博客和项目共用页面规则，分类不平铺后代文章。
- README 是目录介绍，不进入普通文章列表和搜索。
- 标题、日期、标签、摘要及置顶使用当前 [数据契约](../API_CONTRACT.md)。
- 配图统一使用 `文章名-images/`，相对图片及文章链接按源文件位置解析。

## 维护入口

`frontend/scripts/lib/buildContent.mjs` 负责扫描和生成，`frontend/src/vite/contentManifestPlugin.ts` 负责开发监控，`ContentRoute.vue`、`CategoryView.vue`、`ArticleView.vue` 负责展示。

## 验收清单

- 新建目录与 Markdown 自动出现在对应位置，删除后移除入口。
- README 不重复进入文章聚合，空分类可进入，资源目录不作为分类。
- 中文、空格、图片及引用式链接正确，章节锚点能够定位。
- 本地修改触发页面更新；生产构建将实际资源打包到 `frontend/dist/`。
- 使用新规范样例测试，不为历史数据建立兼容分支。

运行命令、验证方式与写作示例见 [前端 README](../../frontend/README.md)。测试数量与通过状态以实际执行结果为准，本次文档修订不重跑产品构建。

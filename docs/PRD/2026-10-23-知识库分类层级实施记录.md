# 三栏分类层级规则

> 当前修订：2026-10-29。知识库、博客和项目使用相同目录规则。

## 层级

栏目首页 → 一级目录 → 任意嵌套子目录 → Markdown 文章。

- 顶部下拉只列首页和一级目录。
- 首页有非空 README 时展示介绍，无介绍时展示直属分类和直属文章入口。
- 分类页显示介绍、直属分类和直属文章，不将更深文章平铺。
- 侧栏只显示当前所属一级目录的树；空分类可导航。
- 一篇 Markdown 对应一个文章页，正文和本文目录共用组件。

## 代码入口

- `frontend/src/composables/contentPaths.ts`：三栏范围、URL 编码和侧栏范围。
- `frontend/src/config/nav.ts`：栏目名称、顺序和菜单。
- `frontend/src/views/CategoryView.vue`：分类与首页行为。
- `frontend/scripts/lib/buildContent.mjs`：内容树、元信息和空分类处理。

## 回归关注

同名嵌套目录、中文路径、空目录、仅含图片的目录，以及有/无 README 的首页都应使用当前规范数据检查。知识库、博客和项目的分类行为必须一致。

规范入口：[前端约定](../FRONTEND_CONVENTION.md)、[内容指南](../SITE_CONTENT_GUIDE.md)。

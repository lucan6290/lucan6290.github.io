# 顶部栏目目录驱动规则

> 当前修订：2026-10-29。本文说明现行目录生成与验收，不作为重新执行计划的指令。

## 当前规则

- `frontend/content/` 一级内容目录生成顶部栏目，空的一级目录也可进入。
- 已知栏目按知识库、博客、项目、关于排序，新栏目按内容树顺序追加。
- 知识库、博客、项目下拉只列首页和直属一级分类，深层内容从分类页和侧栏进入。
- 关于是固定页面，不依赖内容目录。
- 标签与归档在未创建同名内容栏目时使用内置工具页面。

## 配置边界

`frontend/src/config/nav.ts` 保留已知栏目名称、顺序、Logo 和外链；实际分类与文章从内容树生成，不逐项手工登记。

## 验收

- 新增、重命名和删除目录后导航正确更新。
- 窄屏栏目按钮、菜单开关、路由选中及键盘退出行为正确。
- 分类中的 Markdown 进入独立文章页，图片与互链继续可用。
- 以当前文件夹结构测试，不为历史目录增加别名或兼容导航。

详细目录规则见 [FRONTEND_CONVENTION.md](../FRONTEND_CONVENTION.md)，写作规则见 [SITE_CONTENT_GUIDE.md](../SITE_CONTENT_GUIDE.md)。

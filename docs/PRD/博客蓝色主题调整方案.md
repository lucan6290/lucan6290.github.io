# 蓝色主题规范

> 当前修订：2026-10-29。配色以 `frontend/src/styles/tokens.css` 当前变量为事实源，不再维护相互覆盖的多轮色板。

## 方向

保留站点 Logo 和现有阅读布局，以蓝色形成主交互与内容层级；同时改善用户辨识、开发复用和 Agent 定位成本。

## 当前基础变量

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 主交互文字 `--ifm-color-primary` | `#1e5bc8` | `#93b8ff` |
| 强调背景 `--site-accent` | `#79a8ff` | `#93b8ff` |
| 强调文字 `--site-on-accent` | `#0c1b33` | `#0c1b33` |
| 页面背景 `--site-background` | `#ffffff` | `#121a29` |
| 主要表面 `--site-surface` | `#ffffff` | `#1b2940` |

浅蓝背景不等于白底小字号文字色。各组件应根据语义使用强调背景、交互文字和正文变量，不能仅因色相相同就互换。

## 修改入口

- 主题基础：`frontend/src/styles/tokens.css`。
- 全局字体、焦点与基础布局：`frontend/src/styles/base.css`。
- 页面局部状态：对应组件现有样式，复用主题变量。

## 验收

浅深主题都检查正文、日期、按钮、标签、边框、选中态、键盘焦点及语法高亮。窄屏与桌面均核对真实页面，不用单个颜色对的数值替代整页可读性验证。

只修改与具体需求有关的颜色与样式；保护现有导航、目录、搜索和阅读功能。公共约束见 [GLOBAL_STANDARDS.md](../GLOBAL_STANDARDS.md)。

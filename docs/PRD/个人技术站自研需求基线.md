# 个人技术站自研需求基线

> 更新：2026-10-29。本文定义当前产品需求及验收边界，工程字段以 [内容契约](../API_CONTRACT.md) 为准。

## 产品目标

面向在校学生和技术学习者，提供易于查阅的知识库、博客与项目展示。作者通过本地 Markdown 和文件夹维护内容，目录即分类、文章自动呈现。

每次修改必须同时改善用户体验、开发体验和 AI Agent 使用体验，保持现有功能。开发阶段不为历史数据增加兼容分支，使用当前规范的数据验证。

## 内容模型

- `frontend/content/` 是唯一内容事实源，一篇 Markdown 只有一个目录归属，标签用于跨分类聚合。
- 知识库、博客、项目统一逐级展示；分类页只列直属子分类和直属文章。
- README 是目录介绍，不是普通文章；首页有介绍则展示介绍，无介绍则生成分类和文章入口。
- 任意嵌套目录和 Markdown 自动生成导航及页面；无需手工同步分类配置。
- 数字前缀控制目录顺序，分类列表可切换发布日期排序，置顶文章优先。
- 路径由实际目录和文件名生成，不使用 frontmatter 的自定义 URL 字段维持旧地址。

## 内容与页面边界

- 作者在本地编辑 Markdown，当前站点负责只读呈现；登录、在线编辑和多用户管理不属于已实现能力。
- 首页负责阅读入口与近期博客；关于页负责作者、建站目的、内容方法、联系与站点说明。
- 项目按「我的项目」「开源项目与工具」分目录，每个项目独立文件，Fork 标明来源及二次开发。
- 图片按 `文章名-images/` 存放，全文目录来自 `##`、`###`，详情见 [内容指南](../SITE_CONTENT_GUIDE.md)。

## 验收基线

1. 三栏新增目录和 Markdown 后自动可导航，分类列表不平铺更深层文章。
2. 图片、互链、中文路径、空格和章节锚点正确。
3. 切换主题、侧栏、排序和文章时无状态残留，键盘与手机操作可用。
4. 搜索命中正文与中英文关键词，空查询和无结果状态明确。
5. 行为改动运行相关测试与构建，视觉改动检查浏览器页面。
6. 生产目标为 `frontend/dist/`；发布流程及 history 路由刷新需单独验证。

具体命令和结构见 [前端 README](../../frontend/README.md) 与 [工程索引](../DOCUMENTATION_INDEX.md)。

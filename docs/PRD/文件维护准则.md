# 文件维护准则

> 更新：2026-10-29。适用于当前前端内容与工程文档。

## 事实源

| 文件类型 | 维护位置 |
| --- | --- |
| 知识、博客、项目正文及配图 | `frontend/content/` |
| 目录介绍 | 对应目录的 `README.md` |
| 运行与写作说明 | `frontend/README.md` |
| 当前工程规范 | `docs/` 根目录 |
| 需求与专题设计 | `docs/PRD/` |
| 任务实施记录 | `docs/superpowers/plans/` |

## 内容变动

- 新增：创建分类目录、Markdown 和配图，页面与导航自动生成。
- 修改：维护正文及可选日期、摘要，不手工修改生成数据。
- 移动或重命名：同步当前文章互链、图片相对路径和明确引用该路径的文档。
- 删除：核对当前入口与关联链接，按用户授权处理文件。
- 目录介绍用 README；不要求每个分类创建其他索引文件。

## 工程文档变动

- 公共规则、目录、前端、内容和契约分别由对应规范维护，通过 [文档索引](../DOCUMENTATION_INDEX.md) 引用。
- 文档只描述当前事实、明确需求和可复现验收；计划中的功能应标记状态。
- 验证记录注明适用任务，不把一次检查结果永久等同于当前通过。
- 不为历史数据保留兼容分支；不符合新规范的数据可替换并以新数据测试。

## 禁止手工维护的产物

`frontend/src/generated/` 和 `frontend/dist/` 由命令生成。新增内容不维护静态侧栏表、分类注册库或另一份内容清单。

提交按文件精确选择，不自动暂存全部工作区；完整权限与 Git 规范见 [GLOBAL_STANDARDS.md](../GLOBAL_STANDARDS.md)。

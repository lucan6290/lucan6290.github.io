# 视觉与阅读体验规范

> 当前修订：2026-10-29。以当前蓝色主题和共用组件为基准；实际样式值以 `frontend/src/styles/` 为准。

## 目标

读者能清楚找到分类和文章、舒适阅读长文，并使用本文目录及搜索。开发者和 AI Agent 通过统一组件、主题变量和明确规范维护页面，改动保护现有功能。

## 页面职责

- 首页承载站点介绍、近期博客与阅读入口。
- 关于页承载作者、建站目的、内容方法、项目、联系和站点说明；当前顶部不重复首页的两个阅读按钮。
- 三栏共用分类列表和文章排版，区别来自内容而非不同渲染器。
- 项目每篇 Markdown 独立介绍，分类区分自有项目和推荐工具。

## 阅读与响应式

- 正文使用系统字体，展示标题可使用现有文学字体；代码使用等宽字体。
- 长标题保留完整内容；宽表格和代码块在容器内滚动，图片不撑破正文。
- 手机栏目目录默认收起，桌面保留侧栏收起与调宽，状态按现有组件处理。
- “栏目目录”导航其他内容，“本文目录”定位当前正文，名称与入口应清晰。
- 本文目录来自二、三级标题；按钮在右下角，窄屏位于底部操作栏。
- 搜索入口在桌面和窄屏可用，加载、无结果、失败重试和关闭焦点状态清楚。

## 色彩和交互

- 蓝色品牌方向、浅深主题和语义颜色由公共变量维护，详见 [蓝色主题方案](博客蓝色主题调整方案.md)。
- 链接、选中态、悬停、焦点和禁用状态应可识别；不将所有语义颜色统一为品牌色。
- 控件优先使用语义化按钮、链接、标签和对话框，保留键盘操作及减少动态效果设置。

## 验收

在代表性的桌面、平板和手机宽度检查首页、分类、长短文章、项目页、关于页及搜索。浅深主题均验证正文、图片、代码、目录、菜单和核心跳转，浏览器检查不能由构建成功代替。

实现入口与命令见 [前端约定](../FRONTEND_CONVENTION.md)。测试结果以对应任务实际运行记录为准。

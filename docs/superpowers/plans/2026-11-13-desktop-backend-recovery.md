# 桌面后端端口回退与连接恢复实施计划

**目标：** 桌面端优先使用 18000，冲突时启动在系统分配的回环端口，运行中恢复连接时保留编辑缓冲。

**约束：** 仅管理当前 App 持有的进程树；保留 Python 热重载、工作区身份和会话鉴权。14200 保持固定。

- [x] Python 在绑定 18000 遇到地址占用或 Windows 拒绝绑定时，按桌面启动参数回退到端口 0，绑定后写入实际端口。覆盖两类绑定错误，并在本机实际预留端口场景验证启动。
- [x] Rust 使用每次启动独立的会话文件读取实际地址，校验健康信息与令牌，复用可确认的同工作区服务。验证外部服务身份、启动失败和工作区切换。
- [x] Vue 检测断线后有限重连，更新现有连接并保留路由及编辑器，不重放失败请求。在桌面草稿编辑期间停止自有后端，确认重连后文字仍在且未落盘。
- [x] Windows 开发启动前检查 14200，只自动清理能够确认来源的孤立 Vite，活动会话保留。

实际验证发现隐藏启动的 Windows worker 无法可靠收到 Uvicorn 的控制台信号。桌面开发改为用进程事件通知 worker 退出，保留已绑定套接字与会话。实际触发文件变化后，确认新 worker 接收原端口的鉴权请求。

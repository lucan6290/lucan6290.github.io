# 视觉维护与验收计划

> 当前修订：2026-10-29。当前样式基准为蓝色主题，具体修改按用户本次授权执行。

依据：[视觉与阅读体验规范](../../PRD/博客视觉与阅读体验完善方案.md)、[前端约定](../../FRONTEND_CONVENTION.md)。

## 维护入口

- `frontend/src/styles/tokens.css`、`base.css`：公共主题与排版。
- `frontend/src/views/HomePage.vue`：站点介绍、近期博客与三条内容入口。
- `frontend/src/views/CategoryView.vue`、`ArticleView.vue`：共用分类和文章布局。
- `frontend/src/components/layout/Navbar.vue`：栏目、搜索和主题交互。

## 执行顺序

1. 确认当前页面、用户目标与具体修改范围。
2. 使用既有组件、主题变量和数据源实现最小改动。
3. 检查长标题、空列表、宽表格、代码与图片的布局。
4. 检查浅深主题、桌面窄屏及键盘、指针操作。
5. 对行为改动运行相关测试与构建，记录实际结果和剩余问题。

## 验收边界

当前首页近期区域展示按发布日期排序的最近博客；不要将其描述为全站最近更新聚合。分类与搜索复用既有内容管线，不能因视觉改动创建另一套内容或导航数据。

每次修改兼顾用户、开发者和 AI Agent 三种体验，并保护已有功能。本计划不授权自动提交或推送。

# 箓川码笺 Windows 首版实施计划

> **For agentic workers:** Use superpowers:executing-plans and work through the tasks in order.

**目标**：安装后的 Windows 桌面应用能选择博客仓库，自动运行内容后端，并查找、编辑和预览博客文章。

**架构**：保留 Tauri 2、Vue 3 和 FastAPI。发布包携带可直接运行的 Python 后端及其依赖，安装版在应用数据目录保存仓库位置、会话和日志。Markdown 文件仍是内容事实源，版本化保存沿用现有 API。首版范围依据本对话确认的方案。

**约束**：Windows x64 首验，内容服务绑定 `127.0.0.1:18000`。开发版保留热更新。写入验证使用临时博客副本。现有前台改动不混入本次变更。按项目授权在当前工作区实现，不提交 Git。

## 任务一：安装与内容库

- [x] 验证生产入口可以在只有 `frontend/content` 的临时仓库使用，并验证首启目录选择与重启恢复。
- [x] 在 `src-backend/main.py` 区分开发重载与生产直接启动。在 `src-tauri/src/lib.rs` 复用现有进程保护和身份校验，生产会话移到应用数据目录。`src/App.vue` 使用原生文件夹选择，成功连接后才记住目录。
- [x] `npm run tauri:build` 冻结后端并构建 NSIS 安装包。在临时安装路径验证启动后端、连接、退出清理和重开。无效目录及端口占用通过回归验证。

## 任务二：写作、预览和查阅

- [x] 回归覆盖相对图片、不可越界资源及中文全文搜索。用真实 Markdown 验证标题大纲不收录代码块内的伪标题。
- [x] `Editor.vue` 继续通过 `DocumentSession` 保存原文。用 ByteMD 预览当前缓冲，从渲染标题生成大纲。相对图片使用受会话保护的内容服务读取。
- [x] 文档列表沿用现有栏目和目录筛选，新增树形导航和搜索正文、摘要、标签、标题及路径的能力。更新独立内容契约。

## 任务三：交付验证

- [x] 运行桌面前端、内容后端和原生回归，构建 Windows 安装包。在隔离内容库从桌面编辑并保存文章，验证日期、原文和相对图片，并通过前台内容管线检查结果。
- [x] 记录安装包路径和实际验证环境，说明未覆盖的环境。

- 在当前 Windows 11 x64 安装并运行 NSIS 产物。验证选择仓库根目录和直接选择 `frontend/content`，后端自动启动，关闭后释放 18000，重开自动恢复。

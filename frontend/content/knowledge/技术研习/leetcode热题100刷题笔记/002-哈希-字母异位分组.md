# 题解
## 核心思路
字母异位词的本质：**字符串排序后结果完全相同**。
例如 `eat`、`tea`、`ate` 排序后都是 `aet`，以此排序后的字符串作为字典的键，值存放原字符串列表，遍历完成后取出字典所有值即为答案。

### 解法1：排序哈希分组（最直观易懂）
```python
from typing import List

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        hash_dict = {}
        for s in strs:
            # 将字符串字符排序，转为元组
            key = tuple(sorted(s))
            if key not in hash_dict:
                hash_dict[key] = []
            hash_dict[key].append(s)
        # 取出字典中所有分组列表
        return list(hash_dict.values())
```

### 解法2：计数哈希（不排序，统计字母出现次数做键，效率更优）
因为输入仅包含小写26个字母，用长度26的数组记录每个字母出现次数，转元组作为key：
```python
from typing import List

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        hash_dict = {}
        for s in strs:
            count = [0] * 26
            for char in s:
                # 计算字母对应下标 a->0 b->1 ... z->25
                idx = ord(char) - ord('a')
                count[idx] += 1
            key = tuple(count)
            if key not in hash_dict:
                hash_dict[key] = []
            hash_dict[key].append(s)
        return list(hash_dict.values())
```

## 关键语法拆解
1. **`sorted(s)`**
Python内置函数，对字符串`"eat"`排序会得到字符列表 `['a','e','t']`；
列表**不能作为字典的键**，所以用`tuple()`转为元组才可存入字典。

2. **`ord(char) - ord('a')`**
`ord()`是Python内置函数，获取字符ASCII码。
`ord('a')`固定为97，`ord('b')`=98，相减后就能映射到0~25的索引，对应26个英文字母。

3. **字典分组逻辑**
- 不存在该键：新建空列表
- 存在该键：把当前字符串追加进对应列表
最后用`.values()`取出所有分组结果。

## 示例流程演示
输入：`["eat","tea","tan","ate","nat","bat"]`
1. `"eat"`排序→`aet`，字典新增 `(a,e,t): ["eat"]`
2. `"tea"`排序→`aet`，追加进列表 → `["eat","tea"]`
3. `"tan"`排序→`ant`，新建分组
遍历结束后字典的值就是最终分组结果。

# 哈希表解题思路总结
## 一、归类三道题核心本质
| 题目 | 哈希表核心作用 | 题型大类 |
|------|----------------|----------|
| 两数之和 | 用哈希**存遍历过的数据+下标**，快速反向查找需要的另一半 | 查找配对类 |
| 字母异位词分组 | 把**同特征数据映射到同一个key**，实现归类分组 | 分组聚合类 |
| 最长连续序列 | 集合（哈希底层）O(1)查询存在性，标记起点减少重复遍历 | 去重+快速判存类 |

这三类是哈希表最常考的三大模板，后续90%哈希入门题都逃不出这三类逻辑。

## 二、哈希表解题思考四步法
### 步骤1：判断能不能用哈希表（判定标准）
满足下面**任意一条**，优先哈希，暴力循环直接pass：
1. 需要**快速查找某个值是否存在**（查询时间要求O(1)，不能每次遍历数组）
2. 需要**把两个数据做绑定映射**（值→下标、值→计数、特征→原数据列表）
3. 需要**去重**、**分组归类**、**配对匹配**
4. 题目要求时间复杂度不能是O(n²)，必须优化嵌套循环

### 步骤2：确定哈希表的「key（键）」和「value（值）」（最关键一步）
哈希本质就是**key查value**，先定死键值对存什么：
#### 模板1：配对查找类（两数之和）
- 需求：遍历当前元素，找**另一个互补元素**
- key：数组里的数值（用来查互补数有没有出现过）
- value：该数值对应的下标/索引
- 固定套路：
  1. 先算目标互补值 `target - 当前数`
  2. 先查互补值在不在哈希里，在就直接返回结果
  3. 不在就把「当前数:下标」存入哈希

优势：只遍历一遍数组，杜绝双重for循环

#### 模板2：分组归类类（字母异位词分组）
- 需求：把**拥有同一类特征**的元素放到同一个列表
- key：能代表这一组所有元素共性的标识（排序后的字符串/字符计数字典）
- value：列表，存放所有属于该类的原始数据
- 固定套路：
  1. 给每个元素生成唯一分类key
  2. key不存在就新建列表，存在就追加元素
  3. 最后取出所有value就是分组答案

#### 模板3：去重+存在查询类（最长连续序列）
- 简化版哈希：**集合set**（只存key，不需要value，仅用来判断元素是否存在）
- 核心用法：
  1. 原数组转集合，一键去重，查询`x in set`永久O(1)
  2. 找遍历起点，避免重复循环，保证总遍历次数线性O(n)

### 步骤3：规避哈希最容易踩的3个坑
1. **字典key不能是可变类型**
列表`[]`不能当key，必须转成元组`tuple()`（字母异位词排序后列表转元组就是这个原因）；字符串、数字、元组可以做key。
2. **存入哈希的时机不能错**
两数之和必须**先查询、后存入**，否则会把当前元素自己匹配到自己，违反题目“不能使用同一个元素”规则。
3. **缩进与循环作用域**
分组/遍历类题目，return结果**一定要放在循环外部**，否则遍历第一个元素就直接提前结束函数。

### 步骤4：复杂度兜底判断
- 纯哈希单次遍历：时间O(n)，空间O(n)（最优解）
- 排序+哈希：时间O(n log n)，适合数据量小、题目无强复杂度限制时使用

## 三、三类题型题干特征识别（读题判断模板）
### 🔹 看到这些描述 → 用【配对查找哈希模板】
1. 从数组里找**两个数满足某等式**（和/差/积等于目标值）
2. 需要返回元素对应的下标，不能重复使用元素
代表题：两数之和、四数之和、查找重复元素

### 🔹 看到这些描述 → 用【分组聚合哈希模板】
1. “把XX相似的元素分在一组”
2. “可以通过打乱顺序互相得到”“具有相同构成”
代表题：字母异位词、根据用户标签分组、相同后缀字符串归类

### 🔹 看到这些描述 → 用【集合set哈希判存模板】
1. “最长连续xxx序列”
2. “判断数组是否存在重复元素”
3. “查询某个数是否在数组中出现过”
代表题：最长连续序列、存在重复元素、快乐数

## 四、通用总结一句话
**哈希表就是用空间换时间：多开一块内存存映射关系，把原本需要遍历查找的O(n)查询，压缩成O(1)，干掉嵌套循环。**
以后做题先想：我要查什么？要存什么映射？键和值分别放什么？想清楚这两点，哈希题基本就能写出框架。

# 一、哈希核心四大工具
**dict、set、defaultdict、Counter**
### 1\. dict 普通字典（一对一映射）
**适用**：存映射关系（数值→下标、值→状态）
**核心语法**：
- `d[key] = val` 存入
- `key in d` 判断存在（O\(1\)）
- `d.get(key, 默认值)` 安全取值
- `d.values()` 取所有结果（分组题收尾）

**硬性规则**：key 必须不可变（int/str/tuple），**list 不能当 key**。

**代表题**：两数之和

### 2\. set 集合（纯判存、去重）

**适用**：只需要“去重”和“判断是否存在”，不需要存对应数据

**核心语法**：

- `s = set(nums)` 一键去重

- `x in s` 超快查询

- `s.add(x)` 添加元素

**代表题**：最长连续序列

### 3\. defaultdict（自动建列表，分组神器）

**导入**：`from collections import defaultdict`

**适用**：同一 key 对应多个值、分组归类

**优势**：不用写 `if key not in dic`

**标准写法**：

```Plain Text
mp = defaultdict(list)
mp[key].append(val)
```

**代表题**：字母异位词分组

### 4\. Counter（计数神器）

**导入**：`from collections import Counter`

**适用**：统计字符/数字出现次数

**用法**：

```Plain Text
cnt = Counter(s)
cnt['a']       # 取出次数，不存在返回 0
cnt.most_common(k)
```

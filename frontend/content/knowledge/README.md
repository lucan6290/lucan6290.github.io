# 知识库

这里收录我在学习和实践中整理的技术笔记、教程与问题记录。希望把零散的探索沉淀成可以查阅、复习和持续更新的内容。

## 内容分类

### 技术研习

记录 AI、开发工具、算法和 Jetson 等主题的学习笔记，涵盖概念理解、环境配置、常用命令和问题解决。

### 项目实战

整理个人技术站建设、部署运维和开发规范等实践经验，记录实现过程、遇到的问题及解决方法。

## 如何浏览

通过顶部“知识库”菜单选择一级分类，再从分类页或左侧目录进入子分类和文章。文章可以按目录顺序阅读，也可以根据需要直接查阅。

## 内容维护约定

- **按主题分类**：将相关笔记放在对应的一级分类和子目录中，保持目录层级清晰。
- **一篇文章解决一个主题**：标题尽量准确，正文说明背景、步骤、结果或结论，方便日后查找。
- **系列内容使用编号**：需要固定阅读顺序时，在文件名前添加 `01-`、`02-` 等数字前缀。
- **保留上下文**：命令和操作记录尽量注明适用环境、版本及验证结果；整理他人资料时标明来源。
- **持续更新**：发现错误或内容过时后及时修订；重要文章可在文档头部记录日期和更新时间。

知识库内容会随着学习和项目进展持续完善。技术方案可能随环境和版本变化，使用时请结合实际情况验证。

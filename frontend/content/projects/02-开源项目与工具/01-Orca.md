# Orca

## 项目介绍

[Orca](https://github.com/stablyai/orca) 是用于管理多个 AI 编码代理的工作环境。它可以让代理在各自的 Git worktree 中并行工作，并集中查看终端与任务；还提供移动端配套应用，方便跟进任务。

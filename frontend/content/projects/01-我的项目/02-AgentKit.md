# AgentKit

**一次管理，让 Skills 在不同工具和项目中使用。** AgentKit 是一款 Windows 桌面应用，帮助整理 AI Agent Skills，并将它们同步到不同 AI 编程工具的全局或项目级目录。

## 功能亮点

- 集中查看、导入和整理 Skills，使用标签筛选并查看技能内容。
- 按全局或项目范围控制同步，查看各工具的生效状态。
- 检测新安装的工具，并导入已有的 Skills。

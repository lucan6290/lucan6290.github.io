## 箓川码笺

记录、复盘、持续生长。围绕 4 个内容方向、6 个关注主题，长期迭代。

关注主题：AI 探索、前端工程、后端开发、Java 基础、项目复盘、面试准备。

## 这里主要写什么

### 技术笔记

把新技术的学习过程拆成可复盘的路径，沉淀成之后还能快速查阅的知识条目。

### 踩坑记录

记录环境配置、工程实践和调试过程里的问题，也保留解决问题时的判断依据。

### 学习总结

围绕前端、后端、AI 与基础能力做系统整理，让零散输入变成稳定的能力资产。

### 求职经验

整理实习准备、面试复盘和项目表达，用真实经历给之后的自己留一份参考。
